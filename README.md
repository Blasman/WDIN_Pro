              WATCH DOGS INVASION NOTIFIER


What is this?
-------------
This is the 'Pro' version of Watch Dogs Invasion Notifier (WDIN).  
The older (v3.005) 'non-Pro' version of WDIN is available at:  
https://www.nexusmods.com/watchdogs/mods/395

Please see the above linked URL for documentation on features, requirements, etc.  
The 'Pro' version is only available for download on GitHub at:  
https://github.com/Blasman/WDIN_Pro/releases/latest


'Pro' version extra features
----------------------------
Added in the 'Pro' version is the Enhanced Surveillance Module (ESM) terminal window that launches at start-up
in addition to the usual GUI window.

![Screenshot](https://i.imgur.com/keW9Wtk.png)

The ESM window displays an information line and keeps a timestamped history of events as they occur in real
time. The information line displays the type of event and your ping to the other player. It also displays the
country of the other player and optionally their estimated distance from your location via the "Scaled
Antipodal (Surface) Distance" (SAD) value which is a value from 0-1000. 0 == your location and 1000 == max
possible surface distance on earth (~20,015km). In other words: 1 'SAD' value == 20km. SAD display is
disabled by default, you may enable in `config.json` file.

Added in the 'Pro' version are the 'BLOCK' and 'CONN' (connections) GUI buttons (both disabled by default --
you may enable them in `config.json` file).

![Screenshot](https://i.imgur.com/ZCWOzzL.png)

![Screenshot](https://i.imgur.com/uYTz9aN.png)

'BLOCK' will allow you to block players based on their IP address/subnet/ASN using Windows Firewall rules. The
'BFS' button on this menu stands for "Block for Session" where the firewall rule will delete itself when WDIN
exits. There is a 'Manage Firewall Blocks' (the small 'M' button) window where you may right-click on your WDIN
Firewall rules to enable/disable, edit scope, or delete entries easily without having to open Windows Firewall.

'CONN' keeps a history of connections for the current WDIN session. You may right click entries in the
Connections window as an additional way to add the related IP address/subnet/ASN to a Windows Firewall block.


Quick start
-----------
Run `WDIN Pro.exe` (double-click).  
Press the 'Network' button and select the network device that Watch Dogs uses.  
Play Watch Dogs and enjoy WDIN in action.  
Optional: use your own sound files and/or customzie WDIN by modifying `config.json` file.


Files included and/or generated by WDIN Pro
-------------------------------------------
- `config.json` — modifiable config file
- `console.log` — logfile of the ESM window if you enabled 'log_esm_window_to_console_log_file' in `config.json`
- `current_event.txt` — last detected event
- `README.md` — this file
- `sounds/` — default notification audio files
- `WDIN Pro.exe` — main executable


Privacy & safety
----------------
WDIN Pro inspects network packets but does not modify Watch Dogs or its memory. Admin access is required for
reliable packet reading, overlay updates, and for the 'ONLINE', 'DISCONNECT' and 'BLOCK' buttons to function
with Windows Firewall. You may have to set an exception for `WDIN Pro.exe` in your Anti-Virus application in
order for it to not be quarantined. It is what it is.
